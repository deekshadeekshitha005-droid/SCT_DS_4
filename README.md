# SCT_DS_4 - Traffic Accident Data Analysis

## 📌 Project Overview

This project focuses on analyzing traffic accident data to identify patterns related to weather conditions, road conditions, time of day, accident hotspots, and accident severity.

The project uses Python and data visualization techniques to explore accident patterns in a synthetic traffic accident dataset.

---

## 🎯 Objective

To analyze traffic accident data and identify important patterns related to:

- Weather conditions
- Road conditions
- Time of day
- Accident hotspots
- Accident severity

---

## 📊 Dataset

**Dataset:** Synthetic Traffic Accidents Dataset

**Number of Records:** 500

**File Format:** CSV

The dataset contains the following information:

- Accident ID
- Date
- Time of Day
- Weather Condition
- Road Condition
- City
- Severity
- Vehicles Involved
- Injuries

> Note: This dataset was synthetically generated for educational and internship purposes. It does not represent real-world accident statistics.

---

## 🛠️ Technologies Used

- **Python**
- **Pandas** – Data processing and analysis
- **Matplotlib** – Data visualization
- **VS Code** – Development environment

---

## ⚙️ MethodologY

1. Loaded the traffic accident dataset using Pandas.
2. Inspected the dataset structure and information.
3. Checked for missing values.
4. Analyzed accidents based on weather conditions.
5. Studied accidents based on road conditions.
6. Analyzed accident distribution by time of day.
7. Identified accident hotspots by city.
8. Examined accident severity levels.
9. Generated visualizations using Matplotlib.

---

## 🔍 Exploratory Data Analysis

### 1. Weather Condition Analysis

Analyzed the number of accidents associated with different weather conditions.

### 2. Road Condition Analysis

Examined accident frequency under different road conditions, such as dry, wet, and icy roads.

### 3. Time of Day Analysis

Analyzed accident distribution across morning, afternoon, evening, and night.

### 4. Accident Hotspot Analysis

Identified cities with higher numbers of recorded accidents in the dataset.

### 5. Severity Analysis

Explored the distribution of accident severity levels.

## 💡 Key Insights

The analysis helps explore:

- How weather conditions are distributed across recorded accidents.
- How road conditions relate to accident records.
- Which time periods have more recorded accidents.
- Which cities have the highest accident counts in the dataset.
